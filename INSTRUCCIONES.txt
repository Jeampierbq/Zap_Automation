===============================================================
  ZAP AUTOMATION - INSTRUCCIONES DE USO
===============================================================


===============================================================
  INSTALACION (solo la primera vez en cada maquina)
===============================================================

WINDOWS
-------
1. Instalar Python 3 desde https://python.org
   (marcar "Add Python to PATH" durante la instalacion)

2. Clonar o copiar el proyecto a tu maquina.

3. Doble clic en:  instalar_y_ejecutar.bat
   Eso instala las dependencias y arranca el programa solo.


LINUX / MAC
-----------
1. Instalar Python 3:
   sudo apt install python3 python3-pip   (Ubuntu/Debian)
   brew install python3                   (Mac)

2. Clonar o copiar el proyecto a tu maquina.

3. Abrir terminal en la carpeta del proyecto y ejecutar:
   chmod +x setup.sh
   ./setup.sh
   (chmod solo se necesita la primera vez)


===============================================================
  USO NORMAL (cada vez que quieras escanear)
===============================================================

PRE-REQUISITO: tener OWASP ZAP abierto y corriendo.

WINDOWS — ejecutar:
   instalar_y_ejecutar.bat

LINUX/MAC — ejecutar:
   ./setup.sh

O directamente desde terminal:
   Windows:    cd zap-reportes\venv  &&  python main.py
   Linux/Mac:  cd zap-reportes/venv  &&  python3 main.py

El menu interactivo permite:
  [1] Escanear URLs y generar informe Word
  [2] Solo generar Word (con JSONs ya existentes)
  [3] Configuracion (API key, puerto ZAP, URLs)
  [4] Importar JSON exportado de ZAP


===============================================================
  CONFIGURACION (primera vez o nuevo cliente)
===============================================================

1. Abrir ZAP → Herramientas → Opciones → API
   Marcar "Habilitado" y copiar la Clave de API.

2. En el menu del programa, ir a [3] Configuracion
   e ingresar la clave copiada. Se guarda automaticamente.

3. Para cambiar las URLs a escanear, editar:
   zap-reportes/venv/config.py  →  lista URLS


===============================================================
  SOLO REGENERAR WORD (sin escanear)
===============================================================

Si ya tienes los JSON en escaneos/ y solo quieres
regenerar el informe Word sin correr ZAP:

  Windows:    cd zap-reportes\venv  &&  python regenerar_word.py
  Linux/Mac:  cd zap-reportes/venv  &&  python3 regenerar_word.py

Pedira: nombre del cliente, fecha y tipo de caja.


===============================================================
  DONDE QUEDAN LOS ARCHIVOS
===============================================================

  Resultados JSON:   zap-reportes/venv/escaneos/
  Informes Word:     zap-reportes/venv/informes/
  Plantilla Word:    Documento_modelo/


===============================================================
  NOTAS
===============================================================

- Despues de abrir el Word generado, actualizar el indice:
  Clic derecho sobre el area del INDICE → "Actualizar campo"
  → "Actualizar toda la tabla"

- Si algun campo aparece en ROJO en el documento, significa
  que se dejo vacio al generar. Completarlo manualmente.

- La API key de ZAP se guarda en config_user.json (no se
  sube al repositorio). Cada maquina tiene la suya.
